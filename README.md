# Business Website

A responsive and modern business website developed using HTML, CSS, and JavaScript. This website is hosted on GitHub Pages and showcases essential features for a professional online presence.

## Live Demo
[Click here to view the website](https://amanshaw101.github.io/business-website/)

## Features
- **Responsive Design**: Ensures optimal viewing on all devices.
- **Interactive UI**: Smooth animations and user-friendly navigation.
- **Professional Layout**: Clean and modern aesthetic suitable for businesses.
- **Fast Performance**: Optimized for quick loading speeds.
- **GitHub Pages Deployment**: Easily accessible via a GitHub-hosted link.

## Technologies Used
- **HTML**: Structure and content
- **CSS**: Styling and layout
- **JavaScript**: Interactivity and dynamic elements

## Installation & Usage
1. Clone the repository:
   ```sh
   git clone https://github.com/amanshaw101/business-website.git
   ```
2. Navigate to the project directory:
   ```sh
   cd business-website
   ```
3. Open `index.html` in your browser.

## Deployment
This project is deployed using **GitHub Pages**. To update the website:
1. Push changes to the `main` branch.
2. GitHub Pages will automatically reflect the updates.
